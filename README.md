# Análise de Vendas
Desafio do bootcamp de Análise de Dados da DIO, onde devo realizar uma análise de vendas utilizando o Excel como ferramenta para a criação desse Dashboard
Obs: Os dados são fictícios. 
> Ferramenta utilizada: [![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)](https://github.com/mysql)

A planilha estará disponóvel para download para baixar, a análise foi feita dentro do excel e foi feito de maneira simples com o intuito de explorar um pouco a ferramenta.
Sendo assim, fiz 3 perguntas:

- Qual o número de clientes com renovação automática?
- Qual a receita média gerada?
- Qual o impacto dos cupons na receita total?

Foi fazendo essas simples perguntas que eu cheguei na conclusão de quê: **148 pessoas** deixam na assinatura com renovação automática, **147** preferem não o fazer.
Que a receita média é de **R$ 1.754** e que o valor do total dos cupons foi de **R$ 2.122** não sendo um impacto gigantesco se comparado ao lucro que é de **R$ 7.633**.
